# Instruksi Pembuatan Prompt Visual 3D

Saat diminta membuat prompt visual dari naskah episode, ikuti aturan ini:
1. **Analisis Karakter**: Baca deskripsi ciri fisik, pakaian (peci, sarung, koko), dan ekspresi dari folder `referensi_foto/` agar konsisten di semua adegan.
2. **Standar Gaya Visual**: Setiap prompt wajib menggunakan gaya *3D Pixar & Disney animation style, expressive facial features, warm golden hour lighting, Indonesian Islamic boarding school (pesantren) background, cinematic depth of field, 8k resolution, vertical aspect ratio --ar 9:16*.
3. **Output**: Buat 1 prompt detail dalam bahasa Inggris untuk setiap adegan dan simpan ke file `prompts/episode-[nomor]-prompts.txt`.
